# XFCE-Coconut (work in progress)
XFCE-Coconut Is a preconfigured XFCE that I made. Feels like a normal desktop environment, nothing special.

Meant to be installed without XFCE installed, on a bare bones system with nothing on it. You can edit the script to work differently.

You can install with 
`bash <(curl -fsSL https://raw.githubusercontent.com/dinguscool4/XFCE-Coconut/main/install.sh)`
